# DeelTer portfolio

Static Vite + TypeScript portfolio deployed to GitHub Pages.

## Development

- Node.js 22
- `npm ci`
- `npm run dev`
- `npm run build` (TypeScript validation and production build)
- `npm run preview`

## Deployment and routing

Pushes to `main` build the site and publish `dist` to `gh-pages`. Keep `public/CNAME` for the custom domain. Vite uses relative asset paths. Project links use `#project/<slug>` so direct links and refreshes work on GitHub Pages without server rewrites. Legacy `/slug` links require a separate migration and are not generated by this site.

## Design and performance

The monochrome layout uses system fonts, local icons, a 640 x 640 WebP portrait (33,012 bytes), and lazy project thumbnails. No canvas background, autoplay audio, scroll interception, or external icon CDN runs on the page. The interactive connections graph loads near its section, pauses outside the viewport and in hidden tabs, and settles without animation for reduced-motion users. Short interaction animations use transforms and opacity; reduced-motion preferences disable them. Project dialogs support Escape, focus trapping and focus restoration. The icon CSS contains only the selectors used by current content; add new selectors from the licensed Phosphor source if introducing new icons.

## Validation (2026-10-13)

Production build and headless Edge checks passed: all 16 project dialogs and images, category filtering, tools tab, hash-link refresh, Escape, focus trapping and reduced motion. No horizontal overflow at widths 360, 390, 768 and 1024 px. Desktop and mobile screenshots visually reviewed. These are local browser checks, not measured field performance or a guarantee of identical performance on every device.

## Project details

YooKassa describes SDK 2.1.0; installation examples stay pinned to that version. Opening its detail view makes one GitHub Releases API request per page session with a four-second timeout. A valid stable release updates the badge/link using textContent; failures keep the static 2.1.0 link. No token or backend is required on GitHub Pages.

VRCamera uses the mod's local icon and a click-to-load YouTube embed. YouTube receives no iframe request until the visitor presses play; a direct video link remains available. Closing the dialog removes the player.
